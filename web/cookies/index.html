¿Qué son las cookies?

Las cookies son pequeños archivos que un sitio web guarda en tu navegador. Tecnologías similares, como el almacenamiento local (localStorage), cumplen funciones parecidas. Se usan para que la web funcione, para recordar tus preferencias y, si lo permites, para medir el uso de la web y la eficacia de nuestra publicidad.

Google Analytics 4 (Google LLC) nos indica, de forma agregada, qué páginas se visitan y cómo se usa la web. Solo se carga si la aceptas.

Solo se cargan si las aceptas.

Cómo cambiar o retirar tu consentimiento

Puedes cambiar tu decisión cuando quieras con el botón de abajo o con el enlace «Configurar cookies» del pie de cualquier página. Retirar el consentimiento detiene el seguimiento y borra las cookies de analítica y de publicidad que esta web puede eliminar. También puedes borrarlas desde los ajustes de tu navegador (Chrome, Firefox, Safari, Edge). Te volveremos a pedir el consentimiento pasados 13 meses o si cambiamos las cookies que usamos.
